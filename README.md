How to rebuild this site:
First start by ensuring R and Rstudio are downloaded and updated on your laptop.
Then you want to download the docs folder you see in this repository.
You are first going to start with the YML file, and go in and update all of the information so it matches your own, with this you can change the title, what the whole webiste will look like, and more 
Then move to the index, which is one of your most important pages, go through and replace all the information again.
Note you do not need to change anything about the code just the actual text information.
For the index to upload a picture, first save your own, then save it under the rstudio file that is on your device. You will see it show up in the files pane in R.
You can follow this same step for uploading the CV/Resume.
Once you have gone through and updated all of the pages to your own information, you then want to save everything and render.
I like for my rendering to stay in Rstudio, so I have it show up in the viewer pane instead of a link to chrome or edge. 
Go through the site and highlight any changes you want to make once you are content save it one final time again and then open github.
If you don't already have a github account make one, if you do then follow this next step.
Now you want to create a repository that will have the same name as your R studio file for example "paulinegreenwill.github.io"
This allows for your work to be recognized as a website. 
Once you have a repository created you then want to drag and drop the docs folder that is in your Rstudio file. 
After that you are going to create an empty file ".nojekyll"
Once you have done that save everything and wait 1-10 mins. After that you can type the yourname.github.io into your web search and you will see your site!
